Connect to the MCP Server

The Algebras MCP server gives AI agents the platform’s translation, fluency scoring and glossary tools through the Model Context Protocol. Once it is connected, you can ask your agent things like “translate these strings into German with our game glossary” or “extract the terms from this script and add them to a new glossary”, and it calls Algebras for you. See Tools for everything it can do.
URL https://platform.algebras.ai/api/mcp
Transport Streamable HTTP
Authentication x-api-key: <your API key> header

The server is stateless: every request is authenticated with the key, and there is no session to keep alive. Tool calls are billed and limited like the same calls through the API, against the organization the key belongs to.

Get an API Key

Section titled “Get an API Key”

Create a key in the app under API Keys (see API Keys). The key belongs to the organization you create it in, so the agent sees that organization’s glossaries and uses its plan.

Caution

Treat the key like a password. If a config file below holds the key and lives inside a project, add it to .gitignore, or use the variants that read the key from an environment variable or ask for it.

Troubleshooting

Section titled “Troubleshooting”
Problem Cause and fix
401 Unauthorized The x-api-key header is missing, or the key is wrong or deleted. Check the header name (not Authorization) and create a new key if needed.
402 The organization has no active plan or quota left, or has unpaid invoices. See Billing and Plans.
The tools don’t show up Restart the client or reload its MCP servers. In Claude Code, /mcp shows the server status and error.
406 Not Acceptable from curl Send Accept: application/json, text/event-stream. MCP clients do this themselves.
Wrong glossaries The key belongs to another organization. Create a key in the organization you want.
