## Path 1: CLI Quick Start (5 minutes)

The Algebras CLI is perfect for translating localization files in your project. Here's how to get started:

### Step 1: Install the CLI

Install the CLI with [pipx](https://pipx.pypa.io/), which keeps it in its own isolated environment. You'll also need Git installed.

First install pipx:

<Tabs syncKey="os">
<TabItem label="Debian/Ubuntu">
```bash
sudo apt update
sudo apt install pipx
```
</TabItem>
<TabItem label="Fedora">
```bash
sudo dnf install pipx
```
</TabItem>
<TabItem label="Arch">
```bash
sudo pacman -S python-pipx
```
</TabItem>
<TabItem label="macOS">
```bash
brew install pipx
```
</TabItem>
<TabItem label="Windows">
```powershell
python -m pip install --user pipx
```
</TabItem>
</Tabs>

Then add pipx's app directory to your PATH and install the CLI:

```bash
pipx ensurepath
pipx install git+https://github.com/algebras-ai/algebras-cli.git
```

On Windows, run `python -m pipx` in place of `pipx` for both commands, since `pipx` isn't on your PATH until you open a new terminal.

Open a new terminal so the PATH change takes effect, then check the install:

```bash
algebras --version
```

:::caution
Don't install with plain `pip install` on Linux or with Homebrew Python. Those systems block it with `error: externally-managed-environment`. To use a virtual environment instead of pipx, see [Installation](/cli/installation/#method-2-using-a-virtual-environment).
:::

### Step 2: Initialize Your Project

```bash
algebras init
```

This creates a `.algebras.config` file in your project root.

### Step 3: Set Your API Key

```bash
export ALGEBRAS_API_KEY=your_api_key_here
```

### Step 4: Add Languages

```bash
algebras add es fr de
```

### Step 5: Translate Your Files

```bash
algebras translate
```

🎉 **Success!** Your files are now translated. Check the generated language directories.

:::note
The CLI automatically detects your source files and creates translations in the appropriate directories based on your configuration.
:::

## Path 2: API Quick Start (2 minutes)

Make your first translation request in just a few lines of code:

### Step 1: Set Your API Key

```bash
export ALGEBRAS_API_KEY=your_api_key_here
```

### Step 2: Make Your First Translation

```bash
curl -X POST "https://platform.algebras.ai/api/v1/translation/translate" \
     -H "X-Api-Key: $ALGEBRAS_API_KEY" \
     -F "sourceLanguage=auto" \
     -F "targetLanguage=es" \
     -F "textContent=Hello, world!"
```

**Response:**
```json
{
  "status": "ok",
  "timestamp": "2025-01-12T22:31:48.856Z",
  "data": "¡Hola, mundo!"
}
```

🎉 **Success!** You've made your first translation!

## Common Issues & Solutions

### "error: externally-managed-environment"
**Solution:** Your system Python is managed by the OS ([PEP 668](https://peps.python.org/pep-0668/)), so pip won't install into it. Install with pipx as shown in [Step 1](#step-1-install-the-cli), or use a [virtual environment](/cli/installation/#method-2-using-a-virtual-environment).

### "No Algebras configuration found"
**Solution:** Run `algebras init` in your project directory.

### "ALGEBRAS_API_KEY environment variable is not set"
**Solution:** Export your API key: `export ALGEBRAS_API_KEY=your_key`

### "Language 'xx' is not configured"
**Solution:** Add the language: `algebras add xx`

### "401 Unauthorized" API error
**Solution:** Check that your API key is correct and properly set in the `X-Api-Key` header.

### Translation quality issues
**Solutions:**
- Use `--ui-safe` flag for UI-constrained translations
- Upload a glossary for consistent terminology
- Use custom prompts for specific requirements
