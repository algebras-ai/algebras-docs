# Important

Agentic Translation differs from `/translation/translate` and `/translation/translate-batch` endpoints by using an advanced translation pipeline.
Agentic Translation performs translation through multiple iterations, where each iteration fetches relevant context, estimates quality, provides feedback, and measures fluency. In most cases, this approach produces translations that sound more natural and "human-like".

<Aside type="caution" title="Pricing">
  Agentic translation is charged at **4x** the rate of standard translation endpoints, to cover the additional scoring and improvement iterations each request runs through.
</Aside>


## Comparison Table

| Feature | `/translate` | `/translate-batch` | `/agentic-translate` |
|---------|--------------|-------------------|---------------------|
| **Speed** | Fast | Medium | Slower |
| **Translation Size** | Single text | Up to 20 at once | Single text |
| **Price** | Standard rate | Standard rate | 4x standard rate |
| **Fluency** | Good | Good | Excellent (human-like) |
| Glossary support | Yes | Yes | Yes |

## Start Agentic Translation Task

Start an asynchronous agentic translation task.

**Endpoint:** <a href="https://platform.algebras.ai/api/v1#/Translation/post_translation_agentic_translate" target="_blank" rel="noopener noreferrer"><code>POST /translation/agentic-translate</code></a>

### Request Body

Sent as JSON.

| Field | Type | Required | Description |
|---|---|---|---|
| `sourceLanguage` | string | yes | Source language code (use `auto` for automatic detection) |
| `targetLanguage` | string | yes | Target language code |
| `textContent` | string | yes | Text to translate |
| `glossaryId` | string | no | Glossary ID to apply during translation |
| `prompt` | string | no | Custom prompt to guide translation |
| `ignoreCache` | boolean | no | Ignore previously cached translation results |

### Headers

| Header | Required | Description |
|---|---|---|
| `X-Webhook-Url` | no | URL to receive a `POST` notification with the translation result once the task completes |

### Response

**Success Response (200)**

```json
{
  "status": "ok",
  "timestamp": "2025-01-12T22:31:48.856Z",
  "data": {
    "translation_id": "cmabc123translation",
    "status": "PENDING"
  }
}
```

<Aside type="note">
  `status` is `READY` only when the request is an exact cache hit and the result is returned immediately; otherwise it's `PENDING` and you poll the status endpoint below with `translation_id`.
</Aside>

import requests

url = "https://platform.algebras.ai/api/v1/translation/agentic-translate"

## Get Agentic Translation Task Status

Get the status and result of an agentic translation task by ID.

**Endpoint:** <a href="https://platform.algebras.ai/api/v1#/Translation/get_translation_agentic_translate__id_" target="_blank" rel="noopener noreferrer"><code>GET /translation/agentic-translate/\{id\}</code></a>

### Path Parameters

- `id`: The `translation_id` returned from the agentic-translate endpoint

### Response

**Success Response (200)**

```json
{
  "status": "ok",
  "timestamp": "2025-01-12T22:31:48.856Z",
  "data": {
    "id": "cmabc123translation",
    "status": "READY",
    "createdAt": "2025-01-12T22:31:00.000Z",
    "completedAt": "2025-01-12T22:31:48.856Z",
    "result": "Hallo, Welt!",
    "sourceLanguage": "en",
    "targetLanguage": "de"
  }
}
```

`status` is one of `PENDING`, `READY`, or `ERROR`. `result` is present only when `status` is `READY`; `error` is present only when `status` is `ERROR`.

### Example Request

<Tabs syncKey="lang">
<TabItem label="bash">
```bash
curl -X GET "https://platform.algebras.ai/api/v1/translation/agentic-translate/cmabc123translation" \
     -H "X-Api-Key: your_api_key_here"
```
</TabItem>
<TabItem label="python">
```python
import requests

translation_id = "cmabc123translation"
url = f"https://platform.algebras.ai/api/v1/translation/agentic-translate/{translation_id}"
headers = {
    "X-Api-Key": "your_api_key_here"
}

response = requests.get(url, headers=headers)

if response.status_code == 200:
    result = response.json()
    data = result["data"]
    print(f"Status: {data['status']}")
    if data.get("result"):
        print(f"Result: {data['result']}")
else:
    print(f"Error: {response.status_code}")
    print(response.json())
```
