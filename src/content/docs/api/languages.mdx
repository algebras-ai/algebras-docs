## Get Supported Languages

Retrieve a list of all supported languages for translation.

**Endpoint:** <a href="https://platform.algebras.ai/api/v1#/Languages/get_translation_languages" target="_blank" rel="noopener noreferrer"><code>GET /translation/languages</code></a>

### Response

**Success Response (200)**

Returns an object containing the list of supported languages:

```json
{
  "status": "ok",
  "timestamp": "2025-01-12T22:31:48.856Z",
  "data": [
    {
      "language": "en",
      "name": "English"
    },
    {
      "language": "de",
      "name": "German"
    }
  ]
}
```

Each language object contains:

- `language`: Language code
- `name`: Human-readable language name

**Error Response (400)**

Invalid request error structure:

```json
{
  "status": "error",
  "timestamp": "2025-01-12T22:31:48.856Z",
  "error": {
    "message": "Invalid request parameters."
  }
}
```

## Detect Language

Detects the language of a text. It covers the languages of the [supported languages list](#get-supported-languages) and tells you how sure it is, so you can ask the user to confirm when the text is short or the language has a close neighbor.

**Endpoint:** <a href="https://platform.algebras.ai/api/v1#/Languages/post_translation_languages_detect" target="_blank" rel="noopener noreferrer"><code>POST /translation/languages/detect</code></a>

### Request Body

```json
{
  "text": "Selamat pagi, apa kabar?"
}
```

Parameters:

- `text`: Text to detect language from

### Response

**Success Response (200)**

```json
{
  "status": "ok",
  "timestamp": "2026-10-29T10:00:00.000Z",
  "data": "ms",
  "detection": {
    "language": "ms",
    "confidence": 0.71,
    "reliable": false,
    "alternatives": [
      { "language": "id", "confidence": 0.19 }
    ]
  }
}
```

| Field | Description |
|---|---|
| `data` | Detected language code |
| `detection.language` | The same code as `data` |
| `detection.confidence` | Probability that the detected language is right, from 0 to 1 |
| `detection.reliable` | `true` when the confidence is at least 0.8. Short texts and close languages (Malay and Indonesian, for example) are often not reliable: check `alternatives` then, or let the user choose |
| `detection.alternatives` | Up to 3 runners-up with a confidence of at least 0.1, most likely first. Often empty |

<Aside>
  `detection` was added in October 2026. `data` keeps its earlier form, a language code string, so existing integrations keep working.
</Aside>

**Error Response (400)**

Returned when the text has no letters or its language is not one the platform supports.

```json
{
  "status": "error",
  "timestamp": "2026-10-29T10:00:00.000Z",
  "error": {
    "message": "Could not detect the language of the text"
  }
}
```

<TabItem label="python">
```python
import requests

url = "https://platform.algebras.ai/api/v1/translation/languages/detect"
headers = {
    "X-Api-Key": "your_api_key_here",
    "Content-Type": "application/json"
}
data = {
    "text": "Selamat pagi, apa kabar?"
}

response = requests.post(url, headers=headers, json=data)

if response.status_code == 200:
    result = response.json()
    detection = result["detection"]
    print(f"Detected language: {result['data']}")
    print(f"Confidence: {detection['confidence']:.0%}")
    if not detection["reliable"]:
        print("Could also be:", [a["language"] for a in detection["alternatives"]])
else:
    print(f"Error: {response.status_code}")
    print(response.json())
```

package main

import (
    "bytes"

    "fmt"
    "io"

func main() {

    req.Header.Set("X-Api-Key", "your_api_key_here")
    req.Header.Set("Content-Type", "application/json")
    
    client := &http.Client{}
    resp, err := client.Do(req)
    if err != nil {
        panic(err)
    }
    defer resp.Body.Close()
    
    body, _ := io.ReadAll(resp.Body)
    
    if resp.StatusCode == 200 {
        var result map[string]interface{}
        json.Unmarshal(body, &result)
        detection := result["detection"].(map[string]interface{})
        fmt.Printf("Detected language: %v\n", result["data"])
        fmt.Printf("Confidence: %v\n", detection["confidence"])
        fmt.Printf("Reliable: %v\n", detection["reliable"])
    } else {
        fmt.Printf("Error: %d\n", resp.StatusCode)
        fmt.Println(string(body))
    }
}
