Terms live inside a [glossary](/api/glossaries/glossaries/) and carry per-language definitions. A term with a definition in the source and target language of a translation request is eligible to be applied when that glossary is linked via `glossaryId`.

## List Terms

Retrieves a paginated list of all terms for a specific glossary.

**Endpoint:** <a href="https://platform.algebras.ai/api/v1#/Glossaries/get_translation_glossaries__id__terms" target="_blank" rel="noopener noreferrer"><code>GET /translation/glossaries/\{id\}/terms</code></a>

### Path Parameters

- `id`: The glossary ID

### Query Parameters

| Parameter | Type | Required | Description |
|---|---|---|---|
| `page` | integer | no | Page number (default `1`) |
| `limit` | integer | no | Items per page, 1-100 (default `50`) |

### Response

**Success Response (200)**

```json
{
  "status": "ok",
  "timestamp": "2025-01-12T22:31:48.856Z",
  "data": [
    {
      "id": "cmterm123",
      "glossaryId": "cmglossary123",
      "translationFlag": true,
      "createdAt": "2025-01-10T09:05:00.000Z",
      "updatedAt": "2025-01-10T09:05:00.000Z",
      "definitions": [
        { "language": "en", "term": "API", "definition": "Application Programming Interface", "createdAt": "2025-01-10T09:05:00.000Z", "updatedAt": "2025-01-10T09:05:00.000Z" },
        { "language": "de", "term": "API", "definition": "Programmierschnittstelle", "createdAt": "2025-01-10T09:05:00.000Z", "updatedAt": "2025-01-10T09:05:00.000Z" }
      ]
    }
  ],
  "pagination": {
    "page": 1,
    "limit": 50,
    "total": 1,
    "totalPages": 1
  }
}
```

## Create Term

Creates a single term with definitions for one or more languages. All definitions belong to the same term.

**Endpoint:** <a href="https://platform.algebras.ai/api/v1#/Glossaries/post_translation_glossaries__id__terms" target="_blank" rel="noopener noreferrer"><code>POST /translation/glossaries/\{id\}/terms</code></a>

### Path Parameters

- `id`: The glossary ID

### Request Body

Sent as JSON.

| Field | Type | Required | Description |
|---|---|---|---|
| `definitions` | array of objects | yes | Definitions for this term, one per language |
| `definitions[].language` | string | yes | Language code |
| `definitions[].term` | string | yes | The term text |
| `definitions[].definition` | string | yes | Definition of the term |

### Response

**Success Response (200)**

```json
{
  "status": "ok",
  "timestamp": "2025-01-12T22:31:48.856Z",
  "data": {
    "id": "cmterm123",
    "glossaryId": "cmglossary123",
    "translationFlag": true,
    "createdAt": "2025-01-12T22:31:48.856Z",
    "updatedAt": "2025-01-12T22:31:48.856Z",
    "definitions": [
      { "language": "en", "term": "API", "definition": "Application Programming Interface", "createdAt": "2025-01-12T22:31:48.856Z", "updatedAt": "2025-01-12T22:31:48.856Z" },
      { "language": "de", "term": "API", "definition": "Programmierschnittstelle", "createdAt": "2025-01-12T22:31:48.856Z", "updatedAt": "2025-01-12T22:31:48.856Z" }
    ]
  }
}
```

## Create Multiple Terms (Bulk)

Creates multiple terms in one request, each with its own definitions.

**Endpoint:** <a href="https://platform.algebras.ai/api/v1#/Glossaries/post_translation_glossaries__id__terms_bulk" target="_blank" rel="noopener noreferrer"><code>POST /translation/glossaries/\{id\}/terms/bulk</code></a>

### Path Parameters

- `id`: The glossary ID

### Request Body

Sent as JSON.

| Field | Type | Required | Description |
|---|---|---|---|
| `terms` | array of objects | yes | Terms to create |
| `terms[].definitions` | array of objects | yes | Same shape as [Create Term](#create-term)'s `definitions` |

### Response

**Success Response (200) — all terms created**

```json
{
  "status": "ok",
  "timestamp": "2025-01-12T22:31:48.856Z",
  "data": [
    {
      "id": "cmterm123",
      "glossaryId": "cmglossary123",
      "translationFlag": true,
      "createdAt": "2025-01-12T22:31:48.856Z",
      "updatedAt": "2025-01-12T22:31:48.856Z",
      "definitions": [
        { "language": "en", "term": "API", "definition": "Application Programming Interface", "createdAt": "2025-01-12T22:31:48.856Z", "updatedAt": "2025-01-12T22:31:48.856Z" }
      ]
    }
  ]
}
```

**Partial Success Response (207)**

```json
{
  "status": "partial_success",
  "timestamp": "2025-01-12T22:31:48.856Z",
  "data": {
    "successful": [
      {
        "id": "cmterm123",
        "glossaryId": "cmglossary123",
        "translationFlag": true,
        "createdAt": "2025-01-12T22:31:48.856Z",
        "updatedAt": "2025-01-12T22:31:48.856Z",
        "definitions": [
          { "language": "en", "term": "API", "definition": "Application Programming Interface", "createdAt": "2025-01-12T22:31:48.856Z", "updatedAt": "2025-01-12T22:31:48.856Z" }
        ]
      }
    ],
    "failed": [
      { "index": 1, "error": "Definition validation failed", "details": "term is required" }
    ],
    "successCount": 1,
    "failedCount": 1
  }
}
```

<Aside type="note">
  If every term in the batch fails, the response is `400` with the same `failed`-style entries under `error.details` instead of `data`.
</Aside>

## Update Term

Updates a term's definitions.

**Endpoint:** <a href="https://platform.algebras.ai/api/v1#/Glossaries/put_translation_glossaries__id__terms__termId_" target="_blank" rel="noopener noreferrer"><code>PUT /translation/glossaries/\{id\}/terms/\{termId\}</code></a>

### Path Parameters

- `id`: The glossary ID
- `termId`: The term ID

### Request Body

Sent as JSON.

| Field | Type | Required | Description |
|---|---|---|---|
| `definitions` | array of objects | no | Definitions to set. Each item requires `language`; `term` and `definition` are optional per item |

### Response

**Success Response (200)**

```json
{
  "status": "ok",
  "timestamp": "2025-01-12T22:31:48.856Z",
  "data": {
    "id": "cmterm123",

      { "language": "en", "term": "API", "definition": "Application Programming Interface (updated)", "createdAt": "2025-01-10T09:05:00.000Z", "updatedAt": "2025-01-12T22:31:48.856Z" }
```

```json
{

  "data": {

  }
```
