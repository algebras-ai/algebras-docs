A glossary is a set of terms with per-language definitions that can be linked to a translation request (via `glossaryId`) to enforce consistent terminology. See [Glossary Terms](/api/glossaries/glossary-terms/) for managing the terms inside a glossary.

## List Glossaries

Retrieves a paginated list of all glossaries for the organization.

**Endpoint:** <a href="https://platform.algebras.ai/api/v1#/Glossaries/get_translation_glossaries" target="_blank" rel="noopener noreferrer"><code>GET /translation/glossaries</code></a>

### Query Parameters

| Parameter | Type | Required | Description |
|---|---|---|---|
| `page` | integer | no | Page number (default `1`) |
| `limit` | integer | no | Items per page, 1-100 (default `50`) |

### Response

**Success Response (200)**

```json
{
  "status": "ok",
  "timestamp": "2025-01-12T22:31:48.856Z",
  "data": [
    {
      "id": "cmglossary123",
      "name": "Technical Terms",
      "organizationId": "cmorg123",
      "status": "OK",
      "createdAt": "2025-01-10T09:00:00.000Z",
      "updatedAt": "2025-01-10T09:00:00.000Z",
      "languages": [
        { "language": "en", "createdAt": "2025-01-10T09:00:00.000Z", "updatedAt": "2025-01-10T09:00:00.000Z" },
        { "language": "de", "createdAt": "2025-01-10T09:00:00.000Z", "updatedAt": "2025-01-10T09:00:00.000Z" }
      ],
      "terms": []
    }
  ],
  "pagination": {
    "page": 1,
    "limit": 50,
    "total": 1,
    "totalPages": 1
  }
}
```

## Create Glossary

Creates a new glossary with the specified name and languages.

**Endpoint:** <a href="https://platform.algebras.ai/api/v1#/Glossaries/post_translation_glossaries" target="_blank" rel="noopener noreferrer"><code>POST /translation/glossaries</code></a>

### Request Body

Sent as JSON.

| Field | Type | Required | Description |
|---|---|---|---|
| `name` | string | yes | Name of the glossary |
| `languages` | array of strings | yes | Language codes the glossary covers |

### Response

**Success Response (200)**

```json
{
  "status": "ok",
  "timestamp": "2025-01-12T22:31:48.856Z",
  "data": {
    "id": "cmglossary123",
    "name": "Technical Terms",
    "organizationId": "cmorg123",
    "status": "OK",
    "createdAt": "2025-01-12T22:31:48.856Z",
    "updatedAt": "2025-01-12T22:31:48.856Z",
    "languages": [
      { "language": "en", "createdAt": "2025-01-12T22:31:48.856Z", "updatedAt": "2025-01-12T22:31:48.856Z" },
      { "language": "es", "createdAt": "2025-01-12T22:31:48.856Z", "updatedAt": "2025-01-12T22:31:48.856Z" },
      { "language": "fr", "createdAt": "2025-01-12T22:31:48.856Z", "updatedAt": "2025-01-12T22:31:48.856Z" }
    ],
    "terms": []
  }
}
```

## Get Glossary

Retrieves a specific glossary with all its terms and definitions.

**Endpoint:** <a href="https://platform.algebras.ai/api/v1#/Glossaries/get_translation_glossaries__id_" target="_blank" rel="noopener noreferrer"><code>GET /translation/glossaries/\{id\}</code></a>

### Path Parameters

- `id`: The glossary ID

### Response

**Success Response (200)**

```json
{
  "status": "ok",
  "timestamp": "2025-01-12T22:31:48.856Z",
  "data": {
    "id": "cmglossary123",
    "name": "Technical Terms",
    "organizationId": "cmorg123",
    "status": "OK",
    "createdAt": "2025-01-10T09:00:00.000Z",
    "updatedAt": "2025-01-10T09:00:00.000Z",
    "languages": [
      { "language": "en", "createdAt": "2025-01-10T09:00:00.000Z", "updatedAt": "2025-01-10T09:00:00.000Z" },
      { "language": "de", "createdAt": "2025-01-10T09:00:00.000Z", "updatedAt": "2025-01-10T09:00:00.000Z" }
    ],
    "terms": [
      {
        "id": "cmterm123",
        "glossaryId": "cmglossary123",
        "translationFlag": true,
        "createdAt": "2025-01-10T09:05:00.000Z",
        "updatedAt": "2025-01-10T09:05:00.000Z",
        "definitions": [
          { "language": "en", "term": "API", "definition": "Application Programming Interface", "createdAt": "2025-01-10T09:05:00.000Z", "updatedAt": "2025-01-10T09:05:00.000Z" },
          { "language": "de", "term": "API", "definition": "Programmierschnittstelle", "createdAt": "2025-01-10T09:05:00.000Z", "updatedAt": "2025-01-10T09:05:00.000Z" }
        ]
      }
    ]
  }
}
```

<Aside type="note">
  `status` is one of `OK`, `CREATING`, `UPDATING`, `DELETING`, or `ERROR` — reflects background processing on the glossary (e.g. term embedding for retrieval).
</Aside>

## Update Glossary

Updates a glossary's name and/or languages.

**Endpoint:** <a href="https://platform.algebras.ai/api/v1#/Glossaries/put_translation_glossaries__id_" target="_blank" rel="noopener noreferrer"><code>PUT /translation/glossaries/\{id\}</code></a>

### Path Parameters

- `id`: The glossary ID

### Request Body

Sent as JSON. Both fields are optional — send only what you want to change.

| Field | Type | Required | Description |
|---|---|---|---|
| `name` | string | no | New name for the glossary |
| `languages` | array of strings | no | New array of language codes |

### Response

**Success Response (200)**

```json
{
  "status": "ok",
  "timestamp": "2025-01-12T22:31:48.856Z",
  "data": {
    "id": "cmglossary123",
    "name": "Updated Technical Terms",
    "organizationId": "cmorg123",
    "status": "UPDATING",
    "createdAt": "2025-01-10T09:00:00.000Z",
    "updatedAt": "2025-01-12T22:31:48.856Z",
    "languages": [
      { "language": "en", "createdAt": "2025-01-10T09:00:00.000Z", "updatedAt": "2025-01-10T09:00:00.000Z" },
      { "language": "de", "createdAt": "2025-01-10T09:00:00.000Z", "updatedAt": "2025-01-10T09:00:00.000Z" },
      { "language": "fr", "createdAt": "2025-01-12T22:31:48.856Z", "updatedAt": "2025-01-12T22:31:48.856Z" }
    ],
    "terms": []
  }
}
```

## Delete Glossary

{
