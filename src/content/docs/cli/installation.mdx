The Algebras CLI is a Python application. We recommend installing it with pipx, which works on every platform. Choose the method that works best for your environment.

## Prerequisites

- Python 3.12 or higher
- Git (the CLI is installed from its GitHub repository)

## Installation Methods

Algebras CLI is installed directly from its GitHub repository, not from PyPI — always use the `git+` URL form shown below.

:::caution
Don't install with plain `pip install` on most Linux distributions or with Homebrew Python. On Debian/Ubuntu (Python 3.11+), Fedora, Arch and Homebrew, the system Python is "externally managed" ([PEP 668](https://peps.python.org/pep-0668/)), and pip refuses with `error: externally-managed-environment`. Use pipx or a virtual environment instead.
:::

### Method 1: Using pipx (Recommended)

[pipx](https://pipx.pypa.io/) installs Python applications in isolated environments, preventing dependency conflicts with other Python packages.

**1. Install pipx:**

<Tabs syncKey="os">
<TabItem label="Debian/Ubuntu">
```bash
sudo apt update
sudo apt install pipx
```
</TabItem>
<TabItem label="Fedora">
```bash
sudo dnf install pipx
```
</TabItem>
<TabItem label="Arch">
```bash
sudo pacman -S python-pipx
```
</TabItem>
<TabItem label="macOS">
```bash
brew install pipx
```
</TabItem>
<TabItem label="Windows">
```powershell
python -m pip install --user pipx
```
</TabItem>
</Tabs>

**2. Add pipx's app directory to your PATH and install the CLI:**

```bash
pipx ensurepath
pipx install git+https://github.com/algebras-ai/algebras-cli.git
```

On Windows, run `python -m pipx` in place of `pipx` for both commands, since `pipx` isn't on your PATH until you open a new terminal.

**3. Open a new terminal** so the PATH change takes effect.

To upgrade later:

```bash
pipx upgrade algebras-cli
```

### Method 2: Using a virtual environment

If you'd rather not use pipx, install into a virtual environment:

<Tabs syncKey="os">
<TabItem label="Linux/macOS">
```bash
# Debian/Ubuntu only: venv support is a separate package
sudo apt install python3-venv

python3 -m venv ~/.venvs/algebras
source ~/.venvs/algebras/bin/activate
pip install git+https://github.com/algebras-ai/algebras-cli.git
```
</TabItem>
<TabItem label="Windows">
```powershell
python -m venv $HOME\.venvs\algebras
$HOME\.venvs\algebras\Scripts\Activate.ps1
pip install git+https://github.com/algebras-ai/algebras-cli.git
```

If PowerShell reports that running scripts is disabled on this system, allow local scripts for your user first:

```powershell
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
```
</TabItem>
</Tabs>

The `algebras` command is available only while the environment is active. In each new terminal, activate it again first (`source ~/.venvs/algebras/bin/activate` on Linux/macOS).

To upgrade later, activate the environment and run:

```bash
pip install --upgrade git+https://github.com/algebras-ai/algebras-cli.git
```

### Method 3: Using pip

Only use plain pip where the Python installation isn't externally managed: Windows, the python.org installer on macOS, or older Linux distributions such as Ubuntu 22.04.

```bash
pip install git+https://github.com/algebras-ai/algebras-cli.git
```

To upgrade:

```bash
pip install --upgrade git+https://github.com/algebras-ai/algebras-cli.git
```

### Method 4: From Source (Development)

If you want to install the latest development version, clone the repository and install it into a virtual environment:

```bash
git clone https://github.com/algebras-ai/algebras-cli.git
cd algebras-cli
python3 -m venv .venv
source .venv/bin/activate
pip install -e .
```

## Verify Installation

After installation, verify that the CLI is working:

```bash
algebras --version
```

You should see output like:
```
algebras-cli version 1.0.0
```

## Getting Your API Key

Before you can use the Algebras CLI, you'll need an API key to authenticate with the Algebras platform.

### Step 1: Sign Up or Log In

1. Visit the [Algebras platform](https://platform.algebras.ai/)
2. Sign up for a new account or log in to your existing account

### Step 2: Create an API Key

1. Navigate to the [API Keys page](https://platform.algebras.ai/api-keys)
2. Click **"Create API Key"** or **"New API Key"**
3. Give your API key a descriptive name (e.g., "CLI Development Key")
4. Copy your API key immediately - you won't be able to see it again!

:::warning
Keep your API key secure! Never commit it to version control or share it publicly. Treat it like a password.
:::

### Step 3: Set Your API Key

Set the API key as an environment variable in your terminal:

**Linux/macOS:**
```bash
export ALGEBRAS_API_KEY=your_api_key_here
```

**Windows (Command Prompt):**
```cmd
set ALGEBRAS_API_KEY=your_api_key_here
```

**Windows (PowerShell):**
```powershell
$env:ALGEBRAS_API_KEY="your_api_key_here"
```

### Step 4: Make Your API Key Persistent (Optional)

To avoid setting the API key every time you open a new terminal:

**Linux/macOS (bash):**
```bash
echo 'export ALGEBRAS_API_KEY=your_api_key_here' >> ~/.bashrc
source ~/.bashrc
```

**Linux/macOS (zsh):**
```bash
echo 'export ALGEBRAS_API_KEY=your_api_key_here' >> ~/.zshrc
source ~/.zshrc
```

**Windows (Permanent):**
Add it as a system environment variable through System Properties.

:::note
For production environments, consider using a secrets manager or environment variable management tool instead of hardcoding the key.
:::

## Troubleshooting Installation

### "error: externally-managed-environment"

**Cause:** Your system Python is managed by the OS ([PEP 668](https://peps.python.org/pep-0668/)), so pip won't install packages into it. This is the default on Debian/Ubuntu with Python 3.11+, Fedora, Arch and Homebrew Python.

**Solution:** Install with [pipx](#method-1-using-pipx-recommended) or a [virtual environment](#method-2-using-a-virtual-environment). Don't use `--break-system-packages`: it can break OS tools that depend on the system Python.

### "The virtual environment was not created successfully because ensurepip is not available"

**Cause:** On Debian/Ubuntu, venv support is a separate package.

**Solution:**
```bash
sudo apt install python3-venv
```

### "command not found: algebras"

**Cause:** The CLI wasn't added to your PATH.

**Solutions:**
1. **Restart your terminal** after installation
2. **Add pip user bin to PATH:**
   ```bash
   echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.bashrc
   source ~/.bashrc
   ```
3. **Use full path:**
   ```bash
   python -m algebras --version
   ```

### Permission Denied Errors

**Cause:** Insufficient permissions to install packages globally.

**Solution:** Don't install with `sudo pip`. Install with [pipx](#method-1-using-pipx-recommended) or a [virtual environment](#method-2-using-a-virtual-environment). Neither needs admin rights for the CLI itself.

### Python Version Issues

**Cause:** Using an outdated Python version.

**Solutions:**
1. **Check Python version:**
   ```bash
   python --version
   ```
2. **Upgrade Python** to version 3.12 or higher
3. **Use specific Python version:**
   ```bash
   python -m pip install git+https://github.com/algebras-ai/algebras-cli.git
   ```

## Uninstalling

If you installed with pipx:

```bash
pipx uninstall algebras-cli
```

If you installed into a virtual environment, delete it:

```bash
rm -rf ~/.venvs/algebras
```

If you installed with plain pip:

```bash
pip uninstall algebras-cli
```
